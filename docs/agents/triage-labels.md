# Etiquetas de triage

Las skills usan cinco roles canónicos de triage. Este archivo los relaciona con los valores almacenados en `Status:`.

| Rol canónico      | Valor local         | Significado                               |
| ------------------ | ------------------- | ----------------------------------------- |
| `needs-triage`     | `needs-triage`      | Requiere evaluación                       |
| `needs-info`       | `needs-info`        | Espera información adicional              |
| `ready-for-agent`  | `ready-for-agent`   | Está completamente especificado           |
| `ready-for-human`  | `ready-for-human`   | Requiere implementación o decisión humana |
| `wontfix`          | `wontfix`           | No será abordado                           |

Cuando una skill mencione un rol de triage, usa el valor correspondiente de esta tabla.
